# 第 1 章 引言

## FayID 是什麼

FayID 是 iFay 生態中的**統一身份基礎設施**。它為生態內的所有參與者——無論是真實的自然人、由自然人建立的數位人格、面向大眾的共享角色，還是組織實體——提供一套一致的識別、繫結與鑑權兌換機制。

> 一句話定位：FayID 讓每個參與者在 iFay 生態中擁有可驗證、可追溯、可保護隱私的身份。

## 四類主體

FayID 體系圍繞四類核心主體展開：

| 主體 | 說明 |
| --- | --- |
| **自然人（Human Prototype）** | 真實世界中的一個人。每位自然人持有唯一的 Human ID 作為根身份，透過助記詞（Mnemonic）備份。 |
| **數位人格（iFay）** | 自然人在 iFay 生態中建立的 AI 人格。一個人可以擁有多個 iFay，每個 iFay 有獨立的 iFay ID，但都繫結回同一個 Human ID。 |
| **公共角色（coFay）** | 面向大眾的共享角色，可由個人或組織建立並歸屬。每個 coFay 有獨立的 coFay ID 與驗證碼。 |
| **組織（Organization）** | 企業、團隊或其他法人實體。Organization ID 以明文公開，不需要動態碼保護。 |

這四類主體之間的歸屬與繫結關係構成了 FayID 體系的骨架——詳見[第 3 章 實體與關係](./03-實體與關係.md)。

## 為什麼需要 FayID

在傳統網際網路中，一個人往往需要為不同系統維護大量獨立的帳號、密碼、憑證、權杖。FayID 的設計動機來自三個核心訴求：

1. **一人一票，多票聚合**：自然人只需持有一個 Human ID，即可兌換出各類傳統鑑權票據（帳密、Certificate、Access Token、Smart Contract 等），不再逐一記憶。

2. **根身份隱私保護**：Human ID 是根身份，絕不在公開通訊中暴露。對外互動時使用有時效的「動態碼」代替，過期自動輪換，且不同次生成的動態碼之間不可關聯。

3. **為 Global Merit Chain 奠基**：FayID 是 iFay 生態長期信譽體系（Global Merit Chain）的身份層。信譽記錄需要長期累積，但又不能暴露自然人的根身份——FayID 透過不可逆引用（opaqueRef）解決了這一矛盾。

## Global Merit Chain 長期目標

Global Merit Chain（全球信譽鏈）是 iFay 生態的長遠願景：一個去中心化的、可長期累積的信譽記錄系統。在這個系統中：

- iFay ID、coFay ID、Organization ID 作為信譽記錄的主體識別，以明文形式在鏈上可見。
- 自然人的信譽透過不可逆引用間接關聯，既保證了信譽的連續性，又保護了根身份隱私。
- FayID 體系提供的識別、歸屬、撤銷等基礎能力，是 Global Merit Chain 得以運轉的前提。

> FayID 不是 Global Merit Chain 本身，而是它的身份層根基。沒有穩定、可驗證、隱私保護的身份體系，信譽記錄就無從談起。
