# 第 1 章 引言

## FayID 是什么

FayID 是 iFay 生态中的**统一身份基础设施**。它为生态内的所有参与者——无论是真实的自然人、由自然人创建的数字人格、面向公众的共享角色，还是组织实体——提供一套一致的标识、绑定与鉴权兑换机制。

> 一句话定位：FayID 让每个参与者在 iFay 生态中拥有可验证、可追溯、可保护隐私的身份。

## 四类主体

FayID 体系围绕四类核心主体展开：

| 主体 | 说明 |
| --- | --- |
| **自然人（Human Prototype）** | 真实世界中的一个人。每位自然人持有唯一的 Human ID 作为根身份，通过助记词（Mnemonic）备份。 |
| **数字人格（iFay）** | 自然人在 iFay 生态中创建的 AI 人格。一个人可以拥有多个 iFay，每个 iFay 有独立的 iFay ID，但都绑定回同一个 Human ID。 |
| **公共角色（coFay）** | 面向公众的共享角色，可由个人或组织创建并归属。每个 coFay 有独立的 coFay ID 与验证码。 |
| **组织（Organization）** | 企业、团队或其他法人实体。Organization ID 以明文公开，不需要动态码保护。 |

这四类主体之间的归属与绑定关系构成了 FayID 体系的骨架——详见[第 3 章 实体与关系](./03-实体与关系.md)。

## 为什么需要 FayID

在传统互联网中，一个人往往需要为不同系统维护大量独立的账号、密码、证书、令牌。FayID 的设计动机来自三个核心诉求：

1. **一人一票，多票聚合**：自然人只需持有一个 Human ID，即可兑换出各类传统鉴权票据（账密、Certificate、Access Token、Smart Contract 等），不再逐一记忆。

2. **根身份隐私保护**：Human ID 是根身份，绝不在公开通信中暴露。对外交互时使用有时效的"动态码"代替，过期自动轮换，且不同次生成的动态码之间不可关联。

3. **为 Global Merit Chain 奠基**：FayID 是 iFay 生态长期信誉体系（Global Merit Chain）的身份层。信誉记录需要长期累积，但又不能暴露自然人的根身份——FayID 通过不可逆引用（opaqueRef）解决了这一矛盾。

## Global Merit Chain 长期目标

Global Merit Chain（全球信誉链）是 iFay 生态的长远愿景：一个去中心化的、可长期累积的信誉记录系统。在这个系统中：

- iFay ID、coFay ID、Organization ID 作为信誉记录的主体标识，以明文形式在链上可见。
- 自然人的信誉通过不可逆引用间接关联，既保证了信誉的连续性，又保护了根身份隐私。
- FayID 体系提供的标识、归属、撤销等基础能力，是 Global Merit Chain 得以运转的前提。

> FayID 不是 Global Merit Chain 本身，而是它的身份层根基。没有稳定、可验证、隐私保护的身份体系，信誉记录就无从谈起。
